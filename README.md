# GlassPlay-for-Android
Let's be real: a lot of us pay for YouTube Premium but completely ignore the music benefits because the native app's UI just isn't up to par. 

GlassPlay is the open-source sister project to GlassCast, built to fix exactly that. It wraps the YouTube Music catalog in an elegant, Apple Music-inspired UI, replacing native layouts with premium design elements to bridge the gap between YouTube's vast library and top-tier aesthetic standards.

Features:
- Premium Interface: Heavily utilizes rich background blurs, Material UI 3, and animated artwork for album views.   
- Library Organization: Categorically structured like Apple Music, providing native access to pinned albums, playlists, and artists.   
- Immersive Playback: Features a visually striking Now Playing screen, complete with time-synced lyrics.   
- Discovery: Browse native trending charts, new releases, and tailored "Made for You" mixes from YouTube Music.    
- Queue Management: Seamlessly manage Autoplay and upcoming tracks.   
Android TV Support: Sideload the built-in TV variant for a properly optimized, fullscreen free music app on your television.
- Music Videos (Beta): Integrated video playback right from the player.   

Technical Specs & Contribution:
Audio streams are currently limited to the Opus codec at 160 kbps due to backend API restrictions. Since this is a community-driven initiative, PRs and collaborative developer efforts are welcome to help me bypass this streaming quality cap.
